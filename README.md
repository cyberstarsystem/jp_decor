# JP Decor - Luxury Interior Design Website

A premium, high-end luxury interior design website for JP Decor, featuring elegant design, smooth animations, and a modern UI.

## 🎨 Features

- **Luxury Design**: Premium black, gold, and ivory color scheme
- **Fully Responsive**: Mobile-first design that works on all devices
- **Smooth Animations**: AOS (Animate On Scroll) library for elegant transitions
- **Interactive Portfolio**: Filterable gallery with lightbox view
- **Testimonial Slider**: Auto-rotating client testimonials
- **Contact Form**: Beautiful contact form with validation
- **Instagram Integration**: Instagram feed preview section
- **Smooth Scrolling**: Enhanced navigation with smooth scroll effects

## 🚀 Tech Stack

- **HTML5**: Semantic markup
- **CSS3**: Custom luxury styling with animations
- **JavaScript**: Vanilla JS for interactivity
- **Bootstrap 5**: Responsive grid system and components
- **AOS Library**: Animate On Scroll animations
- **Font Awesome**: Icons
- **Google Fonts**: Playfair Display & Poppins

## 🛠️ Setup Instructions

1. **Clone or Download** the project files to your local machine

2. **Open the Project**
   - Simply open `index.html` in your web browser
   - Or use a local server for better performance:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js (http-server)
     npx http-server
     
     # Using PHP
     php -S localhost:8000
     ```

3. **View the Website**
   - Navigate to `http://localhost:8000` (if using a server)
   - Or double-click `index.html` to open in browser

## 🎨 Customization

### Colors
Edit CSS variables in `css/style.css`:
```css
:root {
    --color-black: #0a0a0a;
    --color-gold: #d4af37;
    --color-ivory: #f5f5f0;
}
```

### Fonts
Change fonts in `index.html` Google Fonts link and CSS variables.

### Images
Replace placeholder images with your actual project photos:
- Update `src` attributes in portfolio items
- Update hero background image
- Update Instagram preview images

## 🚀 Deployment

### GitHub Pages
1. Push code to GitHub repository
2. Go to Settings > Pages
3. Select branch and folder
4. Your site will be live at `username.github.io/repository-name`

### Netlify
1. Drag and drop the project folder to Netlify
2. Site will be deployed automatically

### Vercel
1. Import repository to Vercel
2. Deploy with default settings
